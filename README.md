# Modding Mastery

Modding Mastery is a Minecraft mod designed to teach players how to create Minecraft mods intuitively. It allows players to code directly in-game and see the results instantly. This mod is perfect for beginners and intermediate players who want to learn the basics of modding without needing to set up a complex development environment. The mod provides an in-game code editor, a tutorial system, and features to share code with the community.

## Install

1. Download the mod file from the [GitHub releases page](https://github.com/EnderDevelopment/ModdingMastery/releases).
2. Place the downloaded file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded.

## Use

1. Open Minecraft and load a world.
2. Open the in-game code editor by pressing the designated key (default is `P`).
3. Write or edit your mod code in the editor.
4. Compile and run your code to see the results in-game.
5. Use the tutorial system to learn more about modding.
6. Share your code with the community using the built-in sharing feature.
